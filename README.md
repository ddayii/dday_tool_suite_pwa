# DDay Controls Tool Suite — PWA

A Progressive Web App for PLC and robot engineers. Works in any modern browser and can be installed on iOS, Android, or desktop for offline use.

## Live App

**[https://ddayii.github.io/dday_tool_suite_pwa](https://ddayii.github.io/dday_tool_suite_pwa)**

## Tools

- **ASCII Chart** — Full ASCII reference table (0–255) with live search by character, decimal, hex, or control name
- **Scalar Converter** — Convert between decimal, hex, binary, and octal with 8/16/32-bit and signed/unsigned support
- **Unit Converter** — Convert common engineering units

## Install on Your Device

**iOS (Safari only):**
1. Open the live link in Safari
2. Tap the Share button → Add to Home Screen

**Android (Chrome):**
1. Open the live link in Chrome
2. Tap the three-dot menu → Add to Home Screen

**Desktop (Chrome / Edge):**
1. Open the live link
2. Click the install icon in the address bar

Once installed, the app works fully offline.
